# Notes and Tips

### Connect a VPN
* Download VPN file
* Locate file on terminal
* Put on terminal:
```bash
sudo openvpn {vpnfile}
```

___

### Desconnect a VPN
* Put on terminal:
```bash
sudo killall openvpn
```


___

### Connect to ssh
* Put on terminal:
```bash
ssh {username}@{ipaddress}
```
* Then enter the password.
